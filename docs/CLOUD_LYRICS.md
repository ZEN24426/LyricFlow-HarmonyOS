# 云端歌词搜索与候选匹配

## 使用

导入一首音频后，在单曲编辑或歌词编辑页点击“云端搜歌词”。确认搜索词后搜索，查看本地标签与候选的歌曲信息、匹配分和冲突原因，再主动加载歌词预览。可以选择原文、可用的译文，或同时采用原文和译文；双语模式将同一时间点的原文放在上行、译文放在下行，未配对的歌词会保留并提示。遇到无法安全合并的复杂时间格式时需要分别选择。实际显示效果取决于播放器对同一时间点多行歌词的支持。确认采用只更新本次编辑任务；仍需点击保存，才会按所选的副本导出或原文件直写方式处理音频。采用时不替换其他音频标签。

平台没有可用原文但返回了有效译文时，可以单独预览和采用译文；平台明确标记纯音乐、未收录或返回损坏数据时仍会提示错误。搜索、预览和采用均由用户主动发起，不会自动写入音频。

文件夹匹配仍用于本地音频和本地歌词文件配对。另有只补缺失歌词队列，可对用户选择的项目主动搜索并确认候选；扫描本身不会自动向平台批量发送查询，也不会自动写入音频。

## 匹配规则

歌名、歌手、专辑、时长分别最多计 55、30、5、10 分。时长差不超过 2 秒可加分，超过 5 秒禁止推荐；缺失的时长不当作 0 秒参与比较。歌名、歌手需要精确对应，还需要时长或专辑佐证，且第一候选唯一或领先第二候选至少 10 分，才可能突出为推荐。Live、Remix、伴奏等明显版本差异会同时检查标题和专辑。标题或歌手中的组合字符及 `+`、`/`、`&`、`#` 等有含义的差异不会因宽松比较而得到可靠推荐；专辑中这些符号有差异时，该专辑不能作为相同专辑佐证。

文件没有标题标签时，文件名仍可用于搜索，但不会因此自动推荐候选；用户主动修改标题后重新按当前信息判断。人工修改搜索词后，不按原始搜索的推荐条件自动突出结果。若平台返回的候选有损坏、冲突或超出处理上限，可识别的项目仍会展示，且暂停推荐并提示人工核对。

分数用于排序，不是统计置信度或歌词正确率。推荐也不会自动下载、采用或保存歌词；请比较实际版本和歌词时间轴。云端漏标版本词、同名歌曲、重录版等仍可能造成错误候选。

## 网络与数据

- 打开页面不会自动联网。只有主动搜索或预览时才访问网易云音乐 `https://music.163.com`。
- 搜索提交输入框中的搜索词（默认歌名及歌手）；预览提交选中歌曲的数字 ID。请求不会包含音频内容、封面、文件 URI、本地路径、设备标识或账号登录凭据。
- 该平台会按普通网络服务接收访问 IP、查询内容等请求信息。本应用没有额外遥测或云端账号同步。
- 使用系统 HTTPS 证书验证；不使用登录 Cookie、代理或绕过访问限制的流程。平台拒绝、限流或接口不兼容时显示错误，不把错误当作无歌词。
- 请求有超时、取消、重试次数及响应大小限制。只在内存中缓存有限数量的搜索和歌词结果，不持久保存完整搜索历史。
- 接口为平台现有 Web 接口，并非稳定开放 API。搜索范围、内容授权、可访问性和返回格式可能改变；不保证始终可用，不在失败时上传原音频。
- 歌词的权利属于各自权利人；本项目 GPLv3 仅覆盖项目源码及其自有资源，不覆盖第三方歌词。
- 歌词预览会识别仅含纯音乐提示与制作署名的内容；出现明确普通歌词时不会仅凭“纯音乐”字样拒绝。译文数据损坏时保留原文并提示译文不可用。采用后在编辑页标明来源是原文还是译文。
