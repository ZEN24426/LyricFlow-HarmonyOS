# 2.325.799 音频标签依赖替换进度

此工作树以 2.325.799 原始 GPL 源码包为基线，移除 `@dabing/taglib_harmony` 及其运行时原生库，新增项目内标签处理。它是验证中的工作副本，不是正式发布版。

当前主要边界：

- MP3：以有界 ID3v2.3/2.4 文件为主要目标；特殊标志、多个冲突标签或无法安全保全的情况会拒绝。无标签 MP3 须通过完整 MPEG 帧扫描和系统音轨确认。
- FLAC：读取 Vorbis 注释及图片，写入私有副本并检查未编辑元数据与音频帧。歧义注释、部分复杂封面或日期不允许修改。
- RIFF/WAV：仅支持可明确解析的单音轨、单 ID3 标签场景及无标签文件的副本导出；LIST/INFO 等其他标签或复杂块会拒绝。WAV 不开放直写。
- M4A：仅支持部分单音轨、未加密且标签区域有足够固定空间的文件副本导出；ISRC 不支持读取与编辑，其他结构安全拒绝。
- AIFF：仅支持未压缩且不含冲突元数据的 AIFF/AIF 文件副本导出；复杂结构或不够空间时安全拒绝。
- OGG/OPUS：仅支持单流的部分文件副本导出；可在安全边界内重建注释页以容纳长度变化的歌词；多流、特定混排和超限文件会拒绝，封面只读。
- AAC：仅支持部分 MPEG-4 AAC-LC ADTS（无 CRC、单原始数据块、单声道或立体声），可读取和导出副本，系统时长为估算值；依靠逐字节音频帧校验保全内容。添加 ID3 后各播放器兼容性可能不同。
- WMA：仅支持部分单音轨 ASF 的副本导出，需受支持的结构和足够预留空间；曲目/碟片编号与总数修改、数值清空、冲突字段以及不符合要求的封面均拒绝。CUSTOM 色域封面不受支持，含此类原封面的文件即使只改文字也可能拒绝。详见 [WMA 限制与来源](WMA-ASF.md)，不代表一般 WMA 兼容。
